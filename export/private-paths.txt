# The private paths: every tracked path that stays in this repository and is never published.
#
# Each line is deny<TAB>PATTERN, and may add <TAB>NEED. A PATTERN is an exact path or a glob; **
# stands for any number of whole segments and * for part of one segment. This file is itself
# private, so the public allowlist names public paths only. A tracked path a deny line matches
# must match no allowlist line and no other deny line. Two deny patterns may overlap, as the
# last line below overlaps the directory lines, while no tracked path matches both; a copy or
# render line must not overlap any deny pattern, tracked path or not. A deny line must match at
# least one tracked path unless its NEED is optional, for a path that is not in the checkout yet.
