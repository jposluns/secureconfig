# Waivers for tools/check_bracket_ranges.py: lines in fenced bash blocks that hold a bracket
# range or an unclosed `[` and are not validators. One entry per line, three TAB-separated
# fields: <guide-file> TAB <exact physical line text> TAB <reason>. The text is the whole line
# as the block extraction yields it (the opening fence's indentation removed), matched byte
# for byte, never as a substring, and each flagged occurrence of a line consumes one entry.
# The gate fails on an entry no flagged line consumes (a stale allowlist entry) and on an
# empty reason, so remove an entry when its line changes; it also fails on the retired
# in-block waiver comment, so a waiver never lives in a guide. A validator never belongs
# here: it takes a spelled-out set (CONTRIBUTING.md rule 8).
