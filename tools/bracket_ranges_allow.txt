# Waivers for tools/check_bracket_ranges.py, one entry per flagged opener occurrence.
# Four TAB-separated fields: <guide-file> TAB sha256:<span digest> TAB sha256:<block digest> TAB <reason>.
# Each digest is 64 lowercase hex digits. Hash UTF-8 of extracted, newline-normalized text:
# blocks_of converts CRLF and bare CR to LF and removes fence indentation, excluding fences.
# The span is the opener line or, if any opener on it retains a spanning reading, all lines
# from it through block end. Join with LF, no added trailing LF. Hash the whole extracted
# block body separately. Preserve backslashes and remaining whitespace, not joined readings.
# These are not raw-file byte digests; LF-to-CRLF or bare-CR changes alone keep the waiver.
# Edits to any extracted block line or moving the span to a different block body stale it.
# Absolute line numbers are not bound; edits elsewhere in the guide keep the waiver.
# One entry covers all findings on its opener line; later openers need their own entries.
# Duplicate occurrences consume duplicate entries. Changed spans leave stale entries.
# A real validator range is never waived; spell out its set (CONTRIBUTING.md rule 8).
# False positives involving range-free validators need an explicit distinguishing reason.
